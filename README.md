# Apple Clone - AirMug Pro

Apple 제품 페이지 스타일의 스크롤 인터랙션 클론 프로젝트입니다.

## 프로젝트 소개

AirMug Pro라는 가상의 제품 페이지를 Apple 스타일로 구현한 프로젝트입니다.
스크롤에 따라 캔버스 애니메이션, 텍스트 페이드 인/아웃, 이미지 블렌딩 등 다양한 인터랙션이 동작합니다.

## 주요 기능

- **SVG 로딩 애니메이션** - 페이지 진입 시 로딩 인디케이터 표시
- **Canvas 이미지 시퀀스 애니메이션** - 스크롤에 따라 300장의 이미지가 순차적으로 재생되어 영상처럼 보이는 효과
- **스크롤 반응형 텍스트 애니메이션** - 스크롤 위치에 따라 문단이 페이드 인/아웃 및 translateY 이동
- **이미지 블렌딩** - 두 이미지가 스크롤에 따라 자연스럽게 전환되는 효과
- **부드러운 캔버스 렌더링** - requestAnimationFrame과 가속도(acc) 기반의 딜레이 오프셋으로 부드러운 스크롤 구현
- **스크롤 반응 네비게이션** - 스크롤 위치에 따라 로컬 네비게이션 스타일 변경
- **Sticky 레이아웃** - 섹션별 sticky 포지셔닝으로 시네마틱한 스크롤 경험 구현

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API

```
apple-clone/

├── css/
│   ├── default.css
│   └── main.css
├── js/
│   └── main.js
├── images/

```

## 실행 방법

별도의 설치 없이 `index.html`을 브라우저에서 열면 바로 실행됩니다.
단, 이미지 시퀀스 로딩을 위해 로컬 서버 환경에서 실행하는 것을 권장합니다.

```bash
# VS Code Live Server 또는 아래 명령어 사용
npx serve .
```
